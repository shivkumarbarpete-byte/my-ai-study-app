# 📚 my-ai-study-app

An interactive AI-powered study studio application built with **Next.js (App Router)** and **Google Gemini API**. It converts raw study notes and PDFs into structured flashcards, mind maps, timed mock quizzes, and study guides.

---

## 🌐 Live Demo
👉 **[Click Here to Try the Live App](https://my-ai-study-app.vercel.app)**

---

## 🚀 Features
- 📝 **Notes to Flashcards:** Converts raw text notes or PDF files into easy-to-learn flashcards.
- ❓ **Timed Mock Quizzes:** Automatically generates interactive quizzes based on study materials.
- 🗺️ **Mind Maps & Summaries:** Creates clear mind maps and structured study guides.
- 🤖 **Gemini AI Integration:** Fast and accurate AI processing using Google Gemini API.
- ⚡ **Modern Responsive UI:** Built with Tailwind CSS for a seamless desktop and mobile experience.

---

## 🛠️ Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (React)
- **AI Integration:** Google Gemini API (`@google/genai`)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
